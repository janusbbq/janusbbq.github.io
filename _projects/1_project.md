This project explores how large language model agents can support automated modeling and analysis workflows for power-system engineers. The goal is not to replace domain expertise, but to make repetitive study setup, model checking, documentation, and result interpretation more reliable and easier to reproduce.

Current directions include:

- translating engineering study intent into structured analysis steps;
- assisting with model validation and common data-quality checks;
- summarizing power-flow and stability-study outputs in engineer-facing language;
- connecting LLM reasoning with deterministic simulation and optimization tools.
